### T1: Keep YAML anchors and tags as values
- Files: src/extract.rs, docs/backlog.md
- Interfaces: the front-matter lexer treats a value that is only an anchor or tag (`a: &x`,
  `a: !foo`, `a: &x !foo`) as introducing the nested block below it, so that block's URLs get
  their own verbatim spans.
- Test: front matter `links: &l\n  - https://a.test/x\n` and `meta: !thing\n  url: https://a.test/y\n`
  each give one link with `verbatim: true` and a span covering exactly the URL.
- Covers: backlog "A YAML value that is only an anchor or tag (`a: &x`, `a: !foo`) makes the
  lexer skip the nested block, so its URLs fall back to non-verbatim whole-block spans —
  src/extract.rs:421"
- Commit: Keep YAML anchors and tags as values

### T3: Read front matter after a byte-order mark
- Files: src/extract.rs, docs/backlog.md
- Interfaces: `extract` skips a leading U+FEFF before looking for `---` or `+++`; spans stay
  offsets into the original text (shifted by the BOM's 3 bytes) and line numbers are unchanged.
- Test: `"\u{feff}---\ndate: 2020-01-02\nsource: 'https://a.test/x'\n---\n"` gives the date and one
  front-matter link with `Ctx::FrontMatter { quote: Single }` whose span, applied to the original
  text, yields the URL.
- Covers: backlog "A leading UTF-8 BOM hides front matter (no date; values extracted as MdText,
  so writable can't refuse a `'` inside a quoted string); strip it and offset spans by 3 —
  src/extract.rs:530"
- Commit: Read front matter after a byte-order mark
